# kccnc-scout-lab

Tooling lab for kccnc-scout, a project for the Cloud Native Hackathon at KubeCon + CloudNativeCon North America 2026.

kccnc-scout helps attendees find the right talk from what is actually presented. The project itself is built on the hackathon day in a separate repository. This lab checks the pull request loop before that day:

- CI on every pull request (`.github/workflows/ci.yml`)
- Gitar review instructions (`.gitar/review/`)
- Gitar auto-apply criteria (`.gitar/config/apply.md`)

Code in this lab was written with the help of Claude Code.
